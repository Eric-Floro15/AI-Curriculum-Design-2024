## Caveats & Trade-offs the Professor Should Consider

1. **F2022 wave limitation on LLMs and Agentic AI:** Cluster 2 (RAG, agentic frameworks, prompt orchestration) was flagged explicitly as *near-zero frequency* in Fall 2022. These capabilities — now central to applied AI — were nascent in the F2022 labour market. Course 3 covers LLMs as far as the F2022 data supports (LLMs: z=3.05 from NLP table), but a dedicated module on RAG, agents, and modern LLM orchestration would need to be justified by a more recent data wave, not this one. The professor should treat Course 3 as needing a forward-looking extension for current cohorts.

2. **AI Ethics has no lift/z grounding in F2022:** Domain 7 (AI Ethics, Responsible AI, Fairness) produced no statistically significant focal-skill lift table in the F2022 corpus — these concepts were not yet mainstreamed in employer postings. The curriculum embeds Model Interpretability (the only attested proxy, z=2.03) as a cross-cutting thread in Courses 3 and 10. A standalone AI Ethics course would be intellectually appropriate but cannot be market-evidenced from this wave; if the professor adds one, it should be framed as a values-driven academic requirement, not a market-demand pick.

3. **Reinforcement Learning is a thin-signal domain (F2022):** Only 9 skills attested at z≥2 for RL. The curriculum integrates RL as an advanced unit within Course 2 (Deep Learning), not a standalone course. If the program targets autonomous systems or robotics specialisations, a standalone RL course may be warranted by domain expertise, but the F2022 market signal alone does not yet sustain it.

4. **Cluster 8 (SQL/BI) low stability:** This cluster's content (SQL, Tableau, Power BI) is justified by market frequency (not lift/z) and has low internal stability (median membership confidence 0.38). Course 8's skills could alternatively be redistributed into Courses 6 and 7 for a tighter 9-course program — the professor should evaluate whether a dedicated BI/analytics course fits their student profile or whether these tools are better covered as modules.

5. **No peer-program benchmarking was conducted:** This curriculum is grounded entirely in F2022 labour-market clusters and lift/z evidence. A natural next step is to compare this design against peer AI/ML Master's programs (e.g. to check for academic norms, accreditation requirements, or missing elective tracks) — that requires a separate delegation to the University AI Programs Researcher, which was deliberately excluded from this from-scratch design run per the routing rules.
